# Oni2dPlayer

Oni2dPlayer is a C++ GDExtension for Godot 4.7, created as part of the Oni ecosystem.

The project is focused on providing reusable 2D player functionality through C++ while keeping it easy to integrate into Godot projects.

## Current Version

**Version:** `v1.0.0`
**Godot:** `4.7`
**Platform:** `Windows x86_64`

## Project Structure

The GDExtension configuration is located at:

```text
res://oni.gdextension
```

The compiled library used by the extension is located at:

```text
res://bin/oni_framework.dll
```

The expected project structure is:

```text
res://
├── oni.gdextension
└── bin/
    └── oni_framework.dll
```

## Status

Oni2dPlayer is currently in its first public version.

The project will evolve over time with new features, improvements and support for additional platforms and Godot versions.
